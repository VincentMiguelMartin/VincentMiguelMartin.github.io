# Vincent Miguel R. Martin - Portfolio

A responsive, single-file portfolio for GitHub Pages.

## Publish it

1. Sign in to GitHub as `VincentMiguelMartin`.
2. Create a **public** repository named exactly `VincentMiguelMartin.github.io`.
3. Upload `index.html` from this folder to the repository root and commit.
4. Open repository **Settings > Pages**. Under Build and deployment, select **Deploy from a branch**, branch **main**, folder **/(root)**, then Save.
5. Wait for deployment. Open `https://vincentmiguelmartin.github.io/` in a private/incognito window to confirm it works.
6. Paste the working URL into the Portfolio URL field on BlockHub Academy.
